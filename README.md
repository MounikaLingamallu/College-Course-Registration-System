**🎓 College Course Registration System**

A console-based **College Course Registration System** developed using **Core Java**. It allows administrators to manage courses and students to register for and manage their courses.

**🚀 Features**

**👨‍💼 Admin**

- 🔐  Admin Login
- ➕  Add Course
- 📚  View All Courses
- 🔍  Search Course
- 🗑️  Delete Course
- 👨‍🎓  View All Students
- 📋  View All Registrations
- 🚪  Logout

**👨‍🎓 Student**

- 📝  Student Registration
- 🔐  Student Login
- 📚  View Courses
- 🔍  Search Course
- ✅  Register for Course
- ❌  Drop Course
- 📋  View My Registered Courses
- 🚪  Logout

**⚙️ Key Functionalities**

- 🆔 Duplicate Student ID validation
- 📧 Duplicate Email validation
- 🔢 Duplicate Course ID validation
- 💺 Course seat availability
- 🚫 Prevention of duplicate course registration
- ➖ Automatic seat reduction after registration
- ➕ Seat restoration after dropping a course
- 👤 Student-specific registered courses
- 👨‍💼 Admin-specific registration details

**🛠️ Technologies Used**

- ☕ Java
- 💻 Core Java
- 🧩 Object-Oriented Programming
- 📦 ArrayList
- ⌨️Scanner
- 🖥️ Eclipse IDE

**▶️ How to Run**

1. 📂 Open the project in Eclipse.
2. 📄 Open CollegeCourseRegistrationSystem.java.
3. 🖱️ Right-click the file.
4. ▶️ Select **Run As → Java Application**.
